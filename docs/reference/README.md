# Owner reference images

Only owner-provided images that document a decision belong here (for example a payment-page reference or annotated cart/checkout feedback). Agent screenshots, review sheets and measurement images must never be committed; they go to the gitignored `frontend/.artifacts/` or the OS temp dir and are deleted after the written report is updated.
